# 📱 Ежедневки — PWA-приложение для трекинга ежедневных действий

Современное адаптивное PWA-приложение (Progressive Web App) для ведения ежедневных повторяющихся дел («ежедневок»), разработанное на **React + TypeScript + Tailwind CSS + Vite PWA**.

---

## 🌟 Ключевые возможности

1. **Режим «День» (Day View) с корзиной дня:**
   - Чекбокс рядом с каждым действием.
   - При нажатии на галочку действие выполняется и **перемещается в «Корзину дня»**.
   - Из корзины действие можно в любой момент вернуть назад кнопкой **«Вернуть»**.
   - **Автоматическое обнуление в конце дня:** в полночь (при наступлении нового дня) корзина очищается, и ежедневные действия снова появляются активными в новом дне.
   - Возможность как создавать новые действия, так и **удалять их навсегда** (из базы шаблонов).

2. **🌿 Умное исключение действий в Воскресенье (Вс):**
   - Больше не нужно каждую неделю вручную удалять действия на день отдыха!
   - Для каждого действия можно задать дни повторения:
     - Пресет **«Без воскресенья (Пн - Сб)»** — действие автоматически не показывается в воскресенье.
     - «Каждый день», «Будни (Пн-Пт)», «Выходные», либо выборочные дни недели.
   - В воскресенье интерфейс подсвечивает статус дня отдыха.

3. **📊 4 режима отображения:**
   - **День:** фокус на текущих делах, корзина дня, прогресс за день.
   - **Неделя:** обзор 7 дней (Пн-Вс) с прогресс-барами и статусами по каждому действию.
   - **Месяц:** календарная сетка с бейджами продуктивности и переходом к любому дню в один клик.
   - **Год:** GitHub-style тепловая карта активности (52 недели), серии дней (стемки), рекорды и статистика.

4. **✉️ Выбор аккаунта по почте и облачная синхронизация:**
   - Вход и переключение профилей по email (без сложных паролей).
   - Поддержка нескольких профилей на одном устройстве.
   - Опциональная облачная синхронизация между ПК и телефоном через **Supabase (бесплатный тариф)**.
   - Резервное копирование и восстановление в формате JSON в один клик.

5. **⚡ PWA (Работает офлайн и устанавливается как приложение):**
   - Устанавливается на рабочий стол смартфона (Android, iOS) и ПК (Chrome, Edge).
   - Поддержка офлайн-режима благодаря Service Worker.

## 🚀 Варианты безоплатного хостинга

Приложение является статическим PWA, поэтому идеально разворачивается на следующих бесплатных платформах:

### Вариант 1: Vercel (Рекомендуется)
1. Зарегистрируйтесь на [vercel.com](https://vercel.com) (бесплатный тариф Hobby).
2. Загрузите проект на GitHub и нажмите **«Add New Project»** в Vercel.
3. Vercel автоматически определит Vite-проект (`npm run build`, папка `dist`).
4. Нажмите **Deploy**. Вы получите бесплатный HTTPS-адрес вида `https://your-project.vercel.app`.

### Вариант 2: Cloudflare Pages (Очень быстрый мировой CDN)
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages**.
2. Создайте проект Pages, подключив GitHub репозиторий.
3. Build command: `npm run build`, Output directory: `dist`.
4. Нажмите **Save and Deploy**. Неограниченный бесплатный трафик.

### Вариант 3: GitHub Pages
1. В настройках репозитория на GitHub перейдите в **Settings → Pages**.
2. Включите развертывание через GitHub Actions (шаблон Vite / Static HTML).

## ☁️ Настройка бесплатной базы данных Supabase (для синхронизации ПК ⇄ Телефон)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (Free Plan даёт 500 МБ БД и 50 000 пользователей — с запасом на всю жизнь).
2. Создайте новый проект (например, `daily-routines`).
3. Перейдите в **SQL Editor** и выполните команду создания таблицы:
```sql
create table if not exists user_routines (
  user_email text primary key,
  data jsonb not null,
  updated_at timestamp with time zone default now()
);

-- Включение публичного доступа по ключу anon (для личного использования):
alter table user_routines enable row level security;
create policy "Allow all access with anon key" on user_routines
  for all using (true) with check (true);
```
4. В **Project Settings → API** скопируйте:
   - `Project URL`
   - `Project API keys (anon public)`
5. В приложении нажмите на значок аккаунта (почты) вверху справа, включите тумблер **«Включить синхронизацию с облаком»**, вставьте URL и ключ и нажмите **«Сохранить и синхронизировать»**.
6. Теперь при открытии приложения на телефоне или компьютере под одной и той же почтой ваши дела будут моментально синхронизироваться!
